# Atajos de Teclado - Punto de Venta Moresco

## 🎯 Guía Rápida para Cajeros

### 📦 Búsqueda y Selección de Productos

| Tecla | Función |
|:-----:|---------|
| **Escribir código** | Busca productos automáticamente |
| **Enter** ⏎ | Selecciona el primer producto y lo agrega al carrito (solo si hay búsqueda activa) |
| **↑** Flecha Arriba | Navega al producto anterior en la lista |
| **↓** Flecha Abajo | Navega al siguiente producto en la lista |
| **Tab** ⭾ | Limpia la búsqueda para el siguiente producto |
| **F2** o **Esc** | Regresa el foco a la barra de búsqueda |
| **Delete** o **Backspace** 🗑️ | Elimina el último producto del carrito (funciona cuando búsqueda está vacía) |
| **F12** 💰 | Ir a pantalla de pago (botón Pagar) |

### 💳 Pantalla de Pago

| Tecla | Función |
|:-----:|---------|---------|---------|---------|-----|
| **↑ / ↓** | Navega entre métodos de pago disponibles |
| **Enter** | Selecciona método de pago (o valida si está pagado) |

### 🧾 Pantalla de Recibo

| Tecla | Función |
|:-----:|---------|---------|---------|---------|-----|
| **Enter** | Nueva orden (comenzar siguiente venta) |

> **Nota:** El cursor regresa automáticamente al campo de búsqueda para continuar el flujo de trabajo sin mouse.

### ⚖️ Báscula

| Tecla | Función |
|:-----:|---------|
| **Ctrl+B** | Conectar/reconectar báscula |
| **Alt+B** | Enfocar barra de búsqueda |

> **Nota:** El peso se lee automáticamente cuando se selecciona un producto pesable.
>
> **Nueva funcionalidad:** La báscula se reconecta automáticamente al recargar la página. No es necesario desconectar físicamente.

---

## 🚀 Flujo de Trabajo Rápido

### Para productos con peso:

```
1. Escanear código de barras (o escribir)
2. [Enter] → Agrega producto (peso se lee automáticamente)
3. Colocar en báscula (esperar lectura)
4. [Tab] → Siguiente producto
5. [F12] → Ir a pagar
6. [↑/↓] → Seleccionar forma de pago
7. [Enter] → Aplicar pago y validar
8. [Enter] → Nueva orden
```

### Para productos sin peso:

```
1. Escanear código de barras (o escribir)
2. [Enter] → Agrega producto
3. [Tab] → Siguiente producto
4. Cuando termines: [F12] → Ir a pagar
5. [↑/↓] → Seleccionar forma de pago
6. [Enter] → Validar pago
7. [Enter] → Nueva orden
```

### Si necesitas navegar entre varios productos:

```
1. Escribir nombre o código parcial
2. [↓][↓] → Navegar opciones
3. [Enter] → Seleccionar
4. [Tab] → Siguiente producto
... repetir ...
5. [F12] → Pagar
6. [↑/↓] + [Enter] → Seleccionar pago y validar
7. [Enter] → Nueva orden
```

## 💡 Consejos

- ✅ **No necesitas el mouse** - Todo se hace con teclado
- ✅ **El foco vuelve automático** a la barra de búsqueda
- ✅ **Los productos seleccionados** se resaltan en azul
- ✅ **Lectores de código de barras** funcionan automáticamente (emulan teclado)
- ✅ **Trabaja más rápido** sin mover las manos entre teclado y mouse
- ✅ **F12 para pagar** - Cierra la venta sin tocar el mouse
- ✅ **La báscula se reconecta sola** - No necesitas desconectarla físicamente
- ✅ **Flechas en pantalla de pago** - Selecciona forma de pago sin mouse
- ✅ **Enter para todo** - Validar pago y nueva orden, todo con Enter
- ✅ **Delete/Backspace** - Borra el último producto agregado al carrito (funciona cuando búsqueda está vacía)
- ✅ **Enfoque automático** - El cursor vuelve al campo de búsqueda después de nueva orden

## 🔧 Solución Rápida

| Problema | Solución |
|----------|----------|
| No encuentro el producto | Escribe solo parte del nombre y usa ↑↓ |
| La búsqueda no funciona | Presiona **F2** o **Alt+B** |
| No lee la báscula | Espera 15 segundos, se reconecta automáticamente |
| Agregué producto equivocado | Presiona **Delete** o **Backspace** para eliminarlo |
| No puedo pagar | Presiona **F12** para ir a la pantalla de pago |
| Cómo selecciono forma de pago | Usa **↑/↓** y **Enter** en pantalla de pago |

---

## 📌 Notas Importantes

- Presiona **cualquier tecla** para empezar a buscar
- El **Enter** solo funciona cuando hay texto en la búsqueda (evita agregar productos por error)
- **Tab** limpia la búsqueda automáticamente
- El **peso se lee automáticamente** para productos pesables
- **Delete/Backspace** elimina el último producto (funciona cuando búsqueda está vacía o sin foco)
- **F12** para pagar, luego **flechas** para elegir método de pago
- **Enter valida todo**: pago, nueva orden, todo!
- **El cursor vuelve automático** al campo de búsqueda después de cada operación
